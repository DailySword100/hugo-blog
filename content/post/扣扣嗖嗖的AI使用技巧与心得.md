# 扣扣嗖嗖的AI使用技巧与心得

此笔记记录我常用的 Skill、学习到的 Token 节省技巧以及 AI 工作流。

## 先聊清需求，再写代码

第一，需要先聊清需求，再写代码。如果在没有对齐需求的情况下执行，很可能会执行错误，从而返工、浪费 Token。

这里可以使用 Superpowers。这是 GitHub 上的一个开源仓库，内置了非常多好用的工作流与 Skill。

比如：

### brainstorming

在编写代码之前进行，通过提问来完善初步想法、探讨不同方案，并将设计成果分段呈现，以便验证。同时，它还可以保存设计文档。

### using-git-worktrees

使用 Git Worktrees，在设计审批完成之后激活。在分支上创建独立的工作空间，进行项目设置，并验证测试基线是否干净。

### writing-plans

在设计方案获得批准后开始编写计划。将工作分解为若干小块任务，每块大约 2～5 分钟。每个任务都有明确的文件路径、完整代码以及验证步骤。

### subagent-driven-development 或 executing-plans

通过计划激活子代理驱动开发或计划执行。根据任务需求派遣新的子代理工作，整个过程包含两级审核机制：先审核是否符合规范，再审核代码质量；也可以采用批量处理方式，同时由人工监控检查。

## Codex 的 Token 节省方法

在 Codex 的使用中，快速模式的 Token 消耗非常快，性价比也比较低。

可以在个性化设置中，把 Codex 的默认回复语气改成务实，减少废话。

还可以制定让 AI 在运行前读取的规则，例如：

1. 写代码前先分析需求，不确定的问题先向我提问。这样不至于在没搞明白的情况下开始执行，也能减少幻觉。
2. 优先选择简单方案，不要过度设计。

Codex 可以在个性化设置中配置这些规则。至于规则具体应该写什么，可以参考 AI 大神卡帕西放在 GitHub 上的开源规则文件。

## 把项目记忆从长对话迁移到项目中

我在使用 Codex 时发现，项目对话太长以后，再次提问的回复时间会变久，而且 Token 消耗很大。

可以让它把项目架构整理出来。以后直接阅读架构文档，而不是一直回看之前的聊天记录，这样可以减少 Token 消耗。

可以把以下内容直接发给 Codex：

```text
现在这个对话已经非常长。
我要把项目上下文从聊天记录迁移到项目本身，
以后不要依赖这个超长会话来维护项目记忆。

请完整检查当前项目代码和目录结构，并结合我们目前已经完成的工作，
为项目建立长期维护文档。

请创建：
1. /AGENTS.md
2. /docs/ARCHITECTURE.md
3. /docs/PROJECT_STATE.md
4. /docs/DECISIONS.md

要求：

AGENTS.md：
- 保持简短
- 描述项目目标
- 描述主要目录
- 描述开发规则
- 告诉 Codex 开始任务前应该阅读哪些文档
- 不要把完整架构全部塞进 AGENTS.md
- 当架构或项目状态发生明显变化时，需要同步更新 docs

ARCHITECTURE.md：
- 项目整体架构
- 模块划分
- 模块职责
- 模块依赖关系
- 核心类 / Blueprint / System
- 数据流
- 重要资源和代码路径

PROJECT_STATE.md：
- 已完成内容
- 当前正在开发内容
- 已知问题
- 下一步计划

DECISIONS.md：
- 已做出的重要技术决策
- 为什么这样设计
- 放弃过哪些方案以及原因

最重要：
不要只根据聊天记录总结。
请以当前项目真实代码、Blueprint、配置和目录结构为最终依据，
检查文档内容是否与项目实际状态一致。

完成后再检查一遍这些文档是否足以让一个完全没有聊天历史的新 Codex 会话理解项目。
```

完成之后，就可以开一个全新的 Codex 对话，Token 消耗会明显改善。

## 提问技巧

### 1. 提问要明确具体

在提问前，先明确你想从 AI 那里获得什么信息或帮助，这有助于构建针对性的问题。

- 错误示例：“你能告诉我关于月亮的事情吗？”AI 可能回答月亮的形成时间、直径、表面特征以及对地球的影响等宽泛内容。
- 正确做法：“你能告诉我月球的直径是多少公里？”AI 会直接回答月球直径大约为 3,474 公里，精准满足需求。

### 2. 避免歧义

确保问题没有歧义，避免模糊不清的表述，这样 AI 才能准确理解意图。

- 错误示例：“你能解释一下什么是 AI？”
- 正确做法：“你能解释一下什么是人工智能（AI）吗？”AI 会明确回答：“人工智能（AI）是计算机科学的一个分支，它旨在创建能够执行人类智能活动的机器，如学习、推理、自我修正和感知。”

### 3. 指令清晰

如果需要 AI 执行特定任务或操作，确保指令清晰、直接。

- 错误示例：“我需要一些数据。”AI 无法明确所需的数据类型。
- 正确做法：“我需要 2023 年全球智能手机销量的数据。”AI 会给出：“2023 年全球智能手机销量约为 13 亿部，比前一年略有下降”等确切数据。

### 4. 提供上下文

如果问题涉及特定背景信息，提供足够的上下文可以帮助 AI 更好地理解。

- 错误示例：“这本书怎么样？”AI 不知道具体指哪本书。
- 正确做法：“我正在考虑买一本关于心理学的书，你能评价一下《影响力》这本书吗？”AI 会给出：“《影响力》由罗伯特・西奥迪尼所著，这本书深入探讨了说服心理学和影响人们决策的技巧，被广泛认为是心理学领域的经典之作”的针对性评价。

### 5. 突出关键词

在提问时突出关键词，这样 AI 可以更快识别问题核心。

- 错误示例：“我需要一些关于健康饮食的建议。”回答会比较笼统。
- 正确做法：“我需要一些高纤维、低糖的健康饮食建议。”AI 可以针对性地回答：“为了高纤维和低糖的饮食，可以多吃全谷物、豆类、蔬菜和水果，避免含糖饮料和加工食品，选择未加工的糖替代品，如蜂蜜或枫糖浆”等具体建议。

### 6. 使用例子

如果可能，提供一个具体例子，帮助 AI 更准确地把握问题细节。

- 错误示例：“你能告诉我怎么学习编程吗？”AI 需要进一步确认编程语言。
- 正确做法：“我想学习 Python 编程，你能推荐一些适合初学者的学习资源吗？”AI 会推荐适合 Python 初学者的课程等资源。

### 7. 避免有歧义的否定

使用否定时要小心，因为否定句可能让问题变得复杂或模糊。

- 错误示例：“我不认为这个功能是必要的。”
- 正确做法：“我认为这个功能不是必需的。”AI 会据此回应：“如果你认为这个功能不是必需的，我们可以探讨为什么，以及是否有其他更重要的功能需要优先考虑。”

### 8. 分步提问

如果问题很复杂，可以把它分解成几个小问题，逐步提问。

- 错误示例：“你能告诉我怎么建立一个网站吗？”内容过于宽泛。
- 正确做法：“我想建立一个个人网站，首先需要了解域名注册的流程。”AI 会详细说明：“域名注册通常涉及搜索可用域名、选择注册商、支付注册费用并设置域名服务器，我可以详细解释每一步。”

### 9. 反馈和修正

如果 AI 的回答不满足需求，可以提供反馈，并尝试重新表述问题。

- 错误示例：“你之前的回答我没太明白。”
- 正确做法：“你之前提到了 SEO 优化，但我还是不太明白具体怎么做，你能详细解释一下吗？”AI 会进一步阐述：“SEO 优化涉及多个方面，包括关键词研究、高质量内容创作、网站结构优化、外部链接建设等，我可以逐一解释这些步骤。”

### 10. 利用搜索功能

如果问题需要结合搜索结果，可以明确告诉 AI 需要搜索信息来辅助回答。

- 错误示例：“最近有什么新闻？”范围不明确。
- 正确做法：“我想知道 2024 年 12 月的最新科技新闻，你能搜索一下相关信息吗？”AI 会依据搜索结果给出：“根据最新搜索结果，2024 年 12 月的科技新闻包括［具体新闻事件］。”

### 11. 文件和链接

如果问题需要参考文件或网页内容，可以直接上传文件或提供链接。

- 错误示例：“你能帮我分析这个报告吗？”没有提供报告。
- 正确做法：“我上传了一份市场分析报告 PDF，你能帮我分析里面的关键数据吗？”AI 会回答：“我已经分析了你上传的市场分析报告，关键数据包括［具体数据点］。”

### 12. 避免双重否定

双重否定可能让句子更难理解，应尽量避免。

- 错误示例：“我不认为没有证据表明这个理论是正确的。”
- 正确做法：“我认为有证据表明这个理论是正确的。”AI 会回答：“确实有多项研究支持这个理论，我可以提供一些相关文献。”

### 13. 直接提问

直接提出问题，避免添加过多背景，除非这些背景对理解问题至关重要。

- 错误示例：“你能告诉我一些关于这个项目的事情吗？”
- 正确做法：“这个项目的主要目标是什么？”AI 会明确回答：“这个项目的主要目标是［具体目标］。”

### 14. 利用上下文记忆

如果之前提过相关问题，可以在后续对话中说明，以便 AI 根据上下文提供帮助。

- 错误示例：“我需要一些建议。”
- 正确做法：“继我们上次讨论之后，我还需要一些关于职业规划的建议。”AI 会结合上次讨论回答：“根据我们上次的讨论，我建议你考虑［具体建议］。”

### 15. 保持简洁

尽量提出精确的问题，避免模糊或过于宽泛的问题，这样 AI 更容易给出准确答案。

- 错误示例：“我在尝试理解这个非常复杂且难以捉摸的概念，它涉及许多不同领域和理论，你能帮我解释一下吗？”
- 正确做法：“我正在研究量子计算，你能简要解释一下它的基本原理吗？”AI 会简要回答：“量子计算利用量子位（qubits）进行信息处理，与传统二进制位不同，量子位可以同时处于 0 和 1 的状态，这使得量子计算机在处理某些问题时比传统计算机更高效。”

### 16. 角色扮演

给 AI 一个明确身份。

例如：

```text
你现在是一位资深的 <行业> 研究员。
请根据 <主题> 为我找出 3～5 个真实案例。

要求：
1. 案例新颖独特，细节丰富，最好发生在 2020 年以后。
2. 每个案例包含：事件经过、关键转折点、最终结果。
```
